🎯 **What:** The testing gap addressed
The `useMentorSync` hook's internal `streamMentorResponse` API function had missing test coverage for its error paths. Specifically, cases where `fetch` rejected, network responses were not `ok`, or stream reading threw an error midway were untested, and we lacked verification that `finishStreaming()` was reliably called.

📊 **Coverage:** What scenarios are now tested
- Network errors that occur during the initial `fetch` API call.
- HTTP responses where `response.ok` is false.
- Stream interruptions where the `reader.read()` throws an error midway during parsing.

✨ **Result:** The improvement in test coverage
The error paths for the core mentoring streaming feature are now thoroughly tested. Tests assert that the `finishStreaming()` mock from the Zustand store is always correctly called to revert the streaming state in UI, improving test reliability and preventing regressions in edge cases. Tests were added using Vitest and Mocked dependencies for React, Zustand, and Fetch.
