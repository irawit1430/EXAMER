## 2024-06-25 - WhatsApp Webhook Missing Signature Verification
**Vulnerability:** The WhatsApp POST webhook endpoint processed incoming messages without verifying the cryptographic signature `x-hub-signature-256` sent by Meta.
**Learning:** The initial implementation correctly validated the GET endpoint for subscription challenges but missed the POST payload validation. Without signature verification, any external actor could spoof POST requests to trigger AI inference operations and unsolicited messages, leading to resource exhaustion. A crucial learning for mitigating `crypto.timingSafeEqual` length mismatch errors is to hash both the expected and provided signatures before comparison. Furthermore, the Next.js `req.json()` method consumes the body stream, meaning `req.clone().text()` must be used first to construct the HMAC verification payload properly.
**Prevention:** Ensure all public webhook endpoints mandate payload verification matching vendor documentation. Enforce a code review checklist for Webhook API Routes that explicitly requires request signature validation logic and strictly controls body parsing order.
