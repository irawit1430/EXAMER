## 2024-06-25 - Interactive Quiz Options and Feedback Containers
**Learning:** For interactive quiz options that act as toggleable selections, using `aria-pressed` effectively communicates the selected state to screen readers. For dynamically revealed feedback sections (like explanations after answering a question), wrapping them in an `aria-live="polite"` container ensures they are audibly notified without interrupting the user. Additionally, standardizing focus-visible states across these interactive components significantly improves keyboard navigation.
**Action:** When creating or modifying custom selection buttons or toggleable options, always include `aria-pressed`. When revealing content dynamically, evaluate if it requires an `aria-live` region. Consistently apply the `examer` design system's focus utility classes (`focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-brand-primary`) to all custom interactive elements.
