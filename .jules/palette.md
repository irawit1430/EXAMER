\n## 2026-04-22 - Added ARIA labels and focus states to global layout icon buttons\n**Learning:** Icon-only close buttons in global layout components like sidebars and modals are easily missed for accessibility. When improving accessibility, it's critical to add `aria-label` for screen readers and `focus-visible` styles (e.g. `focus-visible:outline-none focus-visible:ring-2`) for keyboard navigation.\n**Action:** Whenever introducing a new icon-only button, always check if an `aria-label` and explicit `focus-visible` styles are present, especially in structural UI elements.
