## 2024-05-24 - Accessibility defaults for custom Toggle components
**Learning:** Custom interactive components, such as a `<button>` used as a toggle switch, often lack the default accessibility attributes and keyboard states that native elements or robust design systems provide. In this app, a custom Toggle was built with an empty generic button shell. It required explicitly adding `role="switch"`, `aria-checked`, and focus ring classes (`focus-visible:ring-2 focus-visible:ring-brand-primary`) to be keyboard-navigable and screen-reader accessible.
**Action:** Always verify if bespoke interactive UI elements have appropriate ARIA roles, states, and keyboard focus indicators natively built-in. Do not assume basic HTML elements inherit these naturally when re-purposed for complex interactions like toggles.
